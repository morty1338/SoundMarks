## Концепция

Карта мира, на которой пользователь отмечает места, с которыми у него ассоциируется песня. К месту привязаны трек, фото/видео и дата. Приложение помогает вспоминать: уведомления «в этот день», пуши при возвращении в место, восстановление старых воспоминаний из истории прослушиваний и галереи. Сквозная визуальная метафора — винил.

Платформа: только iOS (iPhone). Веб-версии нет.

## Стек

- Swift 6, SwiftUI, минимальная версия iOS 17; дизайн Liquid Glass на iOS 26+ с fallback на iOS 17–25
- Хранение: Core Data (`NSPersistentContainer`), только локально
- Карта: MapKit через `MKMapView` в `UIViewRepresentable` (кластеризация через `clusteringIdentifier` / `MKClusterAnnotation`)
- Планета: SceneKit (или RealityKit) — сфера с текстурой ночной Земли (NASA Black Marble, public domain) + звёздный фон
- Анимация заставки: SwiftUI / SpriteKit + AVFoundation (звук) + Core Haptics
- Медиа: PhotoKit (`PHAsset`, `PHPickerViewController`), видео через AVKit
- Локация: Core Location — `CLMonitor` (геозоны), significant location changes (режим путешествия)
- Уведомления: UserNotifications (локальные)
- Друзья: MultipeerConnectivity, QR через Core Image (генерация) и VisionKit `DataScannerViewController` (сканирование), обмен файлом через `ShareLink` / кастомный UTType
- Воспроизведение превью: AVPlayer
- Секреты (токены): Keychain
- SPM, минимум зависимостей (допустимо: ZIPFoundation)
- Архитектура: MVVM, сервисы за протоколами, async/await, корректная изоляция акторов

Всё должно работать с бесплатным personal team: никаких capabilities, требующих платного аккаунта (iCloud, Push Notifications, App Groups и т.п.).

## Источники музыки

Spotify Web API в Development Mode ограничен 5 пользователями из allowlist, владельцу нужен Premium; Extended Quota — только организациям с 250k+ MAU. Поэтому:

- Протокол `MusicSource`:
  1. **SpotifyExportImporter** — импорт Extended Streaming History (JSON в ZIP), API не нужен. Поля: `ts`, `master_metadata_track_name`, `master_metadata_album_artist_name`, `master_metadata_album_album_name`, `spotify_track_uri`, `ms_played`
  2. **LastFmSource** — `user.getRecentTracks` (история + текущий трек)
  3. **SpotifyWebAPISource** — `currently-playing`, `recently-played`, за feature flag
  4. **AppleMusicSource** (MusicKit) — только протокол, реализация позже
- Метаданные и обложки: iTunes Search API → `artworkUrl`, `previewUrl` (30 сек), кэш локально
- Превью: 30-секундный `previewUrl` через AVPlayer

## Модель данных (Core Data)

- **Place**: id (UUID), coordinate, placeName, city, country (reverse geocoding), createdAt, eventDate (год обязателен, месяц и день опциональны), note, pinStyle override, updatedAt, authorProfileId, isDeleted (tombstone для синхронизации), map
- **Track**: id, title, artist, album, artworkURL, previewURL, spotifyURI?, source
- **MediaItem**: id, type (photo/video), localIdentifier (PHAsset) или imageData (для мест от друзей и общих карт), takenAt, order
- **MemoryMap**: id, name, kind (`own` / `friend` / `shared`), ownerProfileId, participants, lastSyncedAt
- **Profile**: id, nickname, avatarData, uniqueCode, isMe, isBlocked, planetVisible (для своего профиля)
- **Trip**: id, name, startedAt, endedAt, связанные Place
- **RoutePoint**: id, latitude, longitude, timestamp, trip
- Все связи с inverse

## Стартовый поток

### Заставка (при каждом запуске)
1. Светлый фон, в центре картинка `SplashRecord` (моя нарисованная пластинка)
2. Звук треска винила, короткая пауза, затем хруст — пластинка трескается и разламывается на осколки, которые разлетаются (разбить изображение на полигональные фрагменты)
3. Одновременно фон плавно затемняется до черноты космоса
4. Из темноты проявляется Земля (переход от тёмного к яркому) — это стартовый экран
- Общая длительность ~2–3 сек, анимация и звук синхронизированы с хаптикой (Core Haptics)
- На беззвучном режиме звук не играет, анимация и хаптика остаются
- Звуки (треск, хруст) — положи заглушки, я подберу файлы (CC0)
- Тап по экрану во время заставки — пропуск

### Стартовый экран — планеты
- Фон: чёрная галактика со звёздами (лёгкий параллакс при вращении)
- В центре: **реалистичная ночная Земля с огнями городов**
- Места пользователя — **маленькие светящиеся точки** на поверхности; видны только на обращённой к экрану стороне; близкие места сливаются в одну точку
- Планету можно крутить пальцем влево-вправо (инерция), сама не вращается
- **Тап по планете** → плавный зум в точку касания (вычислить lat/lon по hit test на сфере) → переход в экран карты, отцентрированный на этой точке
- Справа сверху (Liquid Glass): **шестерёнка** (настройки), под ней **«F»** (экран друзей)
- Снизу по центру: **плашка «N пластинок»** — количество мест на текущей планете; тап открывает рулетку этой планеты
- **Свайп между планетами:**
  - центр — моя планета
  - справа — планеты друзей, у которых включена видимость (только просмотр)
  - слева — общие карты
  - соседняя планета чуть выглядывает с края экрана, намекая, что там что-то есть
  - под каждой планетой друга — аватар и никнейм; под общей — «Общая карта: ты и [никнейм]»
- Тап по планете друга или общей карте открывает её карту тем же зумом

## Экран карты

Раскладка (все кнопки Liquid Glass, без контуров, минимум 44×44 pt):
- **Справа сверху:** шестерёнка (настройки)
- **Под ней:** вертикальный ползунок-таймлайн — капсула, бегунок показывает год (например «2026»); верхнее положение — текущий год (все места); тянешь вниз — более ранние годы; карта показывает места **до выбранного года включительно**; хаптика на каждом шаге года; пины появляются/исчезают с анимацией
- **Под ползунком:** кнопка «моё местоположение»
- **Снизу по центру:** «+» — добавить место (на планете друга скрыта)
- **Справа снизу:** иконка **стопки виниловых пластинок** — открывает рулетку
- **Возврат к планете:** если сильно отдалить карту (порог высоты камеры), плавный переход обратно к экрану планет
- Пины и кластеризация — см. ниже

### Пины
- Сам виниловый диск без подложки (~44 pt), обложка трека в центре, тень и блик для объёма
- Альтернативный стиль в настройках — проигрыватель
- Пин вращается, пока играет превью
- **Первый тап:** снизу выезжает компактная карточка: обложка, трек, артист, короткое название места (POI или район, не полный адрес), дата без обрезки; сразу играет превью
- **Второй тап** (по карточке) → детальный экран

### Кластеризация
- При отдалении близкие пины — «стопка винила» с числом, сверху обложка самого свежего места
- Тап: приближение; если пины в одной точке — раскрытие веером/списком
- Плавно при 1000+ местах

## Рулетка пластинок

- Горизонтальный ряд **2D-пластинок**, листается свайпом влево-вправо (snap к центру)
- Пластинка — голый диск, **обложка занимает не меньше 70 % диаметра диска**
- Выбранная (центральная) пластинка крупнее и ярче, остальные меньше и приглушены
- **Над каждой пластинкой:** «Город · дд.мм.гггг» (например «Berlin · 25.09.2026»)
- **Под пластинкой:** название трека — мелко и аккуратно, в одну строку с обрезкой, не заходит на соседние пластинки
- **Над первой пластинкой:** кнопка «Фильтры» — сортировка/группировка: по дате, по стране, по году
- Первый тап по центральной пластинке — играет превью; второй тап — детальный экран места. Тап по боковой пластинке — прокрутка к ней
- Если центральная пластинка остаётся выбранной дольше 5 секунд — она начинает медленно вращаться
- Рулетка показывает места текущей планеты (своей, друга или общей)

- Плашка трека: квадратная обложка, название, артист, play/pause
- Коллаж фото/видео: пейджинг свайпом с индикатором страниц, тап — на весь экран
- Даты: «Datum der Erinnerung» и «Hinzugefügt»
- Заметка
- Внизу мини-карта места
- Меню «…»: редактировать, удалить, **Поделиться** (шеринг-карточка, см. ниже)
- Закрытие свайпом вниз

## Друзья (локально, без сервера)

### Профиль
- Никнейм, аватар (фото или инициалы с цветом), уникальный код (генерируется на устройстве, 8 символов, неизменяемый)
- Создаётся при первом открытии экрана друзей; редактируется в настройках

### Экран друзей (кнопка «F»)
- Мой код + QR-код с ним
- «Добавить друга»:
  - **Рядом:** сканировать QR друга → устройства связываются через MultipeerConnectivity → оба подтверждают запрос → друзья
  - Ручной ввод кода — для подтверждения при подключении рядом
- Список друзей: аватар, никнейм, дата последней синхронизации
- Профиль друга: «Создать общую карту», «Синхронизировать», «Удалить друга», «Заблокировать»
- Входящие запросы: принять / отклонить

### Синхронизация
- **Рядом (MultipeerConnectivity):** когда друзья рядом и приложение открыто — автоматический обмен: моя планета (если видимость включена) и общие карты. Передаются только изменения с `lastSyncedAt`
- **Издалека (файл):** кнопка «Отправить обновление» — экспорт снимка моей карты или общей карты в файл кастомного типа (`.soundmap`, zip: JSON + сжатые JPEG фото, видео — только превью-кадр) → `ShareLink` (AirDrop, Telegram, Сообщения). Открытие файла в приложении (onOpenURL / document types) импортирует обновление, только если отправитель в списке друзей и не заблокирован
- Планета друга — **только просмотр**, это снимок на момент последней синхронизации; показывать «обновлено N дней назад»
- **Общая карта:** оба добавляют места; слияние по UUID, при конфликте правок — last-writer-wins по `updatedAt`, удаления через tombstone
- **Видимость:** переключатель в настройках «Моя планета видна друзьям». Если выключен — моя карта не передаётся, а у друзей при следующей синхронизации моя планета удаляется
- Info.plist: `NSLocalNetworkUsageDescription`, `NSBonjourServices`, `NSCameraUsageDescription`

### Режим путешествия
- «Начать поездку» → significant location changes в фоне, `RoutePoint` локально

- Trip открывается как история
